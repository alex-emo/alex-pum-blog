# OPT-12 内容结构与信息架构

| 项目 | 内容 |
| --- | --- |
| 优先级 | P2 |
| 预计工时 | 6 h |
| 涉及文件 | `app/routers/pages.py`、`app/templates/`、`app/models.py`、`app/services/posts.py`、`app/migrations/` |
| 风险 | 中（涉及路由与模型） |

## 问题

当前站点导航只有 **文章 / 标签 / RSS** 三项，搜索藏在侧栏（移动端还要先展开侧栏）。作为一个写了"碎碎念""散文""算法"三类内容的个人博客，发现性偏弱。

| # | 缺失 | 影响 |
| --- | --- | --- |
| 1 | **无「关于」页** | 读者不知道你是谁，个人博客的灵魂没了；SEO 上也没有 `Person` 实体的载体 |
| 2 | **无归档（按年月）** | 文章稍多之后，翻旧文只能靠分页；`sitemap` 有但人没法看 |
| 3 | **无「相关文章」** | 阅读完一篇文章后只能点"上一篇/下一篇"（按时间序），不是主题相关的 |
| 4 | **无系列 / 合集** | 「碎碎念：博客搭建的不完整过程」这类文章天然成系列 |
| 5 | **标签未受控** | 每篇最多 8 个，但标签总量会随写随建；tags 页现在只有 5 个，还不严重，但要及时止住 |
| 6 | **搜索入口不明** | 主导航没有搜索；按 `s` 或 `/` 也无快捷键 |
| 7 | **无订阅之外的"关注我"** | 社交图标只有 X / Telegram / 邮箱 |

## 方案

### 1. 关于页（半天）

- 路由 `GET /about`，用 Markdown 写，存 DB（新增 `Page` 模型）或直接放模板。
- 内容：自我介绍、技术栈、联系方式、`rel="me"` 链接（见 OPT-15）。
- JSON-LD 加 `Person` + `sameAs` 列表。
- 主导航加第 4 项「关于」。

### 2. 归档页（半天）

- `GET /archive`：按年分组，`<details>` 折叠，每条是 `时间 · 标题 · 标签`。
- 或者按月聚合 `GET /archive/2026/11`（对 SEO 更好，但页面会多）。
- 数据：`select id, title, slug, published_at from posts order by published_at desc`，一次查询搞定。

### 3. 相关文章（1 天）

最轻的实现——**按共享标签数排序**：

```sql
SELECT p.*, COUNT(pt.tag_id) AS shared
FROM posts p JOIN post_tags pt ON pt.post_id = p.id
WHERE pt.tag_id IN (?, ?, ?) AND p.id != ? AND p.status = 'published'
GROUP BY p.id ORDER BY shared DESC, p.published_at DESC LIMIT 3
```

在文章页底部加「相关文章」区块（3 条）。等文章 > 50 篇再考虑向量检索，现在没必要。

### 4. 系列（可选，1 天）

`Post.series`（字符串） + `Post.series_order`（整数）两个字段；文章页显示"本系列共 N 篇"的目录。
**先不做，等真的写系列了再说。**

### 5. 标签收敛

- 后台标签管理页：合并标签、改名、删除（删除时校验引用）。
- 写作时用 autocomplete（`<datalist>`）建议已有标签，减少同义重复。
- 规则：单篇文章 ≤ 5 个标签（现在 8 个偏多），标签总量 ≤ 20，超过就合并。

### 6. 搜索入口 + 快捷键

- 主导航「标签」旁边或页头加一个搜索图标（移动端常驻）。
- 全局快捷键：`s` 或 `/` 聚焦搜索框（注意：输入框内不触发）。
- 搜索框加 `type="search"`（已有）+ `enterkeyhint="search"`。

### 7. 关注入口

- RSS 已经有；可选加 **邮件订阅**（Buttondown / Listmonk 自建），对"碎碎念"这类内容比 RSS 更有效。
- `rel="me"` + microformats2（见 OPT-15）。

## 验收

- [ ] `/about` 可从主导航进入，移动端折叠菜单里也在。
- [ ] `/archive` 在 4 篇文章时展示正常，造 50 篇假数据时不卡（查询无 N+1）。
- [ ] 文章页底部出现 3 条相关文章，且不含当前文章。
- [ ] 按 `/` 聚焦搜索框，按 Esc 失焦。
- [ ] 标签页数量与后台标签管理一致，无孤儿标签。
