# OPT-03 社交分享卡与默认图

| 项目 | 内容 |
| --- | --- |
| 优先级 | P0 |
| 预计工时 | 1 h |
| 涉及文件 | `app/templates/base.html`、`app/templates/post.html`、`app/static/img/` |
| 风险 | 低 |

## 问题

`og:image` 只在 `post.cover_image` 存在时输出（`post.html` 的 `{% block og_image %}`），因此：

- **首页、标签页、搜索页分享出去是无图卡片**；
- **没有封面的文章**也是无图卡片；
- `twitter:card` 固定为 `summary`（小图卡），即使有图也用不上 `summary_large_image` 的大图排版；
- 无 `og:image:width` / `og:image:height` / `og:image:alt`，部分抓取器（微信、Telegram 部分客户端）会二次下载或直接降级。

## 方案

### 1. 生成默认图

做一张 1200×630 的站点默认卡片（深色底 + 站名 + 一句签名 + 头像），导出 `og-default.png`（≤ 200 KB，建议再出 `og-default.webp`），放 `app/static/img/`。

### 2. base.html 提供可覆盖的默认块

```html
{% set share_image = share_image_url|default(settings.site_url ~ '/static/img/og-default.png') %}
<meta property="og:image" content="{{ share_image }}">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="{{ og_title }}">
<meta name="twitter:card" content="{% block twitter_card %}summary_large_image{% endblock %}">
<meta name="twitter:image" content="{{ share_image }}">
<meta name="twitter:image:alt" content="{{ og_title }}">
```

**必须用绝对 URL**（含 `https://`），相对路径在多数抓取器里无效。

### 3. 文章页覆盖

`post.html` 里若 `post.cover_image` 存在：

```jinja
{% set share_image_url = settings.site_url ~ post.cover_image %}
```

封面图比例建议 clamp 到 1.91:1，否则 Telegram / 微信会裁切中间。

### 4. 微信 / QQ 额外标签（可选，10 行）

```html
<meta itemprop="image" content="{{ share_image }}">
<meta name="twitter:site" content="@ParameciumAlex">
```

## 验收

- [ ] 微信"发送给朋友""分享到朋友圈"、Telegram、Discord、X 四处预览均出图，且为 1200×630 不裁切。
- [ ] [Open Graph 调试器](https://developers.facebook.com/tools/debug/) 与 [Twitter Card Validator](https://cards-dev.twitter.com/validator) 无警告。
- [ ] 首页、标签页、搜索页、无封面文章、有封面文章四种情况各验一次。
- [ ] 抓取后 `curl -s <url> | grep -o 'og:image[^>]*'` 能看到绝对地址。

## 附：验证用命令

```bash
curl -s https://blog.pum.org.cn/ | grep -oE '<meta (property|name)="(og|twitter):[a-z:_]+" content="[^"]*"'
```
