# OPT-08 触控目标、焦点可见性与减少动效

| 项目 | 内容 |
| --- | --- |
| 优先级 | P1 |
| 预计工时 | 2 h |
| 涉及文件 | `app/static/css/style.css` |
| 风险 | 低 |

## 问题（WCAG 2.2 相关三条新增标准）

### 1. SC 2.5.8 Target Size (Minimum) —— 目标 ≥ 24×24 CSS px

线上文章页实测 9 处小于 24×24：

| 元素 | 实测尺寸 | 位置 |
| --- | --- | --- |
| 分页数字 `4` / `5` | **9×22** | 分页条 |
| 社交图标 邮箱 / X / Telegram | **19×19** | 侧栏 profile-actions |
| RSS 徽章 | 23×24 | 侧栏 |
| 页脚「管理」 | 27×24（宽够，高刚好卡线） | 页脚 |
| tag「算法」 | 42×23 | 卡片标签 |
| 侧栏统计数字 | 9×22 | `dl.profile-stats dd` |

### 2. SC 2.4.13 Focus Appearance —— 焦点可见

`.profile-search input:focus` 与 `.field input:focus` 使用：

```css
outline: none;
border-color: var(--accent);
```

只靠 1px 边框变色示意焦点，周长和对比度都低于 2.4.13 的建议值（≥ 2px 周长、≥ 3:1 对比）。**键盘用户可以摸黑打字。**

### 3. `prefers-reduced-motion` 缺失

`.theme-toggle:active { transform: scale(.94) }`、卡片 hover 过渡、`transition: color .15s, border-color .15s, transform .15s` 等动效在用户系统开启"减少动态效果"时依然播放。

## 方案

### 1. 目标尺寸

统一加一个工具类或直接改各组件：

```css
/* 分页：数字按钮最小 24 */
.page-btn { min-width: 2.3rem; min-height: 2.3rem; display: inline-grid; place-items: center; }

/* 移动端建议 44px（WCAG 2.5.5 AAA / iOS HIG） */
@media (max-width: 720px) {
  .page-btn, .theme-toggle { min-width: 44px; min-height: 44px; }
}

/* 社交图标：图标本身 19px，用 padding 把可点区域撑到 24+ */
.profile-actions a { display: inline-flex; align-items: center; justify-content: center;
                     min-width: 28px; min-height: 28px; }

/* tag chip 高度补到 24 */
.tag { padding: .15rem .55rem; line-height: 1.6; min-height: 24px; display: inline-flex; align-items: center; }

/* 统计数字是链接，撑开可点区域 */
.profile-stats dd a { display: inline-block; padding: .1rem .25rem; }

/* 页脚链接 */
.footer-links a { display: inline-block; padding: .25rem .4rem; }
```

> 注意：SC 2.5.8 允许"不足 24px 但与相邻目标之间有 ≥ 24px 间距"的例外，但本站分页数字、社交图标都是**相邻紧密排列**，属于必须改的典型场景。

### 2. 焦点可见

```css
/* 全局兜底：只在键盘导航时显示（避免鼠标点击出现丑陋描边） */
:focus-visible {
  outline: 2px solid var(--accent);
  outline-offset: 2px;
  border-radius: 4px;
}

/* 输入框：保留 outline，不要 none */
.profile-search input:focus-visible,
.field input:focus-visible,
.field textarea:focus-visible {
  outline: 2px solid var(--accent);
  outline-offset: 1px;
  border-color: var(--accent);
}
```

Safari ≤ 15 不支持 `:focus-visible`，可用 `@supports not selector(:focus-visible)` 回退。

### 3. 减少动效

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
    scroll-behavior: auto !important;
  }
  .theme-toggle:active { transform: none; }
}
```

### 4. 顺带：`theme-color` 与 CSS 对齐

`base.html` 里 `<meta name="theme-color">` 是 `#fbfaf7` / `#16161a`，CSS 实际是 `#f6f8fb` / `#0f141a`，两者不一致，移动端浏览器地址栏会有色差。改成与 `--bg` 一致，并在 `theme.js` 的 `apply()` 里**同步更新 meta**（手动切主题时也改），否则 OS 深色 + 手动浅色时地址栏还是黑的。

```js
function syncThemeColor(mode) {
  var meta = document.querySelector('meta[name="theme-color"]:not([media])');
  if (!meta) { meta = document.createElement('meta'); meta.name = 'theme-color'; document.head.appendChild(meta); }
  meta.content = root.dataset.theme === 'dark' ? '#0f141a' : '#f6f8fb';
}
```

## 验收

- [ ] 用 DevTools 的 "Show tap targets" 或 axe 跑一遍，**0 个 target-size 告警**。
- [ ] 键盘 Tab 遍历整页（Tab → Enter → Shift+Tab），焦点环始终可见、不被遮挡（SC 2.4.11）。
- [ ] 系统开启"减少动态效果"后，主题按钮点击无缩放动画。
- [ ] 移动端真机或 iPhone 模拟器：分页数字、社交图标单手可点中。
- [ ] 手动切换深浅主题时，地址栏颜色同步变化。
