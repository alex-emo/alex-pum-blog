# OPT-07 对比度修正（WCAG 2.2 AA）

| 项目 | 内容 |
| --- | --- |
| 优先级 | P1 |
| 预计工时 | 1 h |
| 涉及文件 | `app/static/css/style.css`（`:root` 与 `html[data-theme="dark"]`）、`app/static/css/pygments.css` |
| 风险 | 低（纯视觉，但需两套主题各截图比对） |

## 问题

WCAG 2.2 AA 对普通文本要求 **4.5 : 1**，大字（≥ 24 px 或 ≥ 18.66 px 粗体）要求 **3 : 1**。实测（浅色主题）：

| 变量 | 值 | 背景 | 对比度 | 用在哪 | 结论 |
| --- | --- | --- | --- | --- | --- |
| `--fg-faint` | `#8b9cb0` | `#f6f8fb` | **2.64 : 1** | 卡片时间/阅读量/评论数、页脚版权与链接、`·` 分隔点 | ❌ 严重不达标 |
| `--fg-faint` | `#8b9cb0` | `#ffffff` | 2.81 : 1 | 同上（白底场景） | ❌ |
| `--accent` | `#2f6fed` | `#f6f8fb` | **4.27 : 1** | 普通链接文字、hover 态 | ❌ 略低于 4.5 |
| `--accent` | `#2f6fed` | `#ffffff` | 4.55 : 1 | 白底链接 | ✅ 勉强 |
| `--fg-muted` | `#5b6b7c` | `#f6f8fb` | 5.14 : 1 | 次要文本 | ✅ |
| 正文 | `#16202b` | `#f6f8fb` | 15.47 : 1 | 正文 | ✅ |
| tag 前景 | `#1b53c4` | `#e8efff` | 5.91 : 1 | 标签 | ✅ |
| tag hover | `#ffffff` | `#2f6fed` | 4.55 : 1 | 标签 hover | ✅ 勉强 |

深色主题反而**全部达标**（faint 4.69、muted 8.07、tag 8.73），不需要动。

## 方案

### 浅色主题改两个值

```css
:root {
  /* --fg-faint: #8b9cb0;  → 2.64:1 */
  --fg-faint: #5f7085;     /* 4.76 : 1 on #f6f8fb，4.99:1 on #fff */
  /* --accent: #2f6fed;     → 4.27:1 */
  --accent: #2a63d6;       /* 5.12 : 1 on #f6f8fb，5.45:1 on #fff */
}
```

备选（若希望保留更浅的辅助色层次，把"元信息"和"页脚"分开）：

| 用途 | 推荐值 | 对比度 |
| --- | --- | --- |
| `--fg-faint`（元信息/页脚） | `#5f7085` | 4.76 : 1 |
| `--fg-muted`（次要说明） | `#5b6b7c` | 5.14 : 1 |
| `--accent`（链接） | `#2a63d6` | 5.12 : 1 |

### 检查副作用

`--accent` 变更会影响：

1. **链接 hover** —— 白字 on `#2a63d6` = 5.45 : 1 ✅
2. **tag hover** —— 白字 on `--accent`，从 4.55 → 5.45 ✅ 更好
3. **`.theme-toggle:hover`、`.brand:hover`** 的边框/文字色 —— 都是非文本，无对比度要求
4. **`--accent-soft` / `--accent-strong`** —— 若由 accent 派生需同步检查（当前是独立值 `#e8efff` / `#1b53c4`，tag 对比度 5.91 ✅ 不受影响）
5. **`pygments.css`** —— 语法高亮配色与 accent 无关，但代码块的注释色（通常是低对比重灾区）需要单独量一次

### 顺便量一下代码块

```bash
# 用 Chrome DevTools Lighthouse 或 axe 跑一次文章页，代码块注释色最容易挂
npx @axe-core/cli https://blog.pum.org.cn/<数学文章 slug>
```

## 验收

- [ ] axe DevTools 在首页、文章页、标签页、搜索页 **0 个 color-contrast 错误**（浅色 + 深色各跑一次）。
- [ ] 两种主题截图对比，层次感没有明显塌陷（改完 `--fg-faint` 从"很淡"变成"次要灰"，视觉上可以接受）。
- [ ] 代码块内注释、行号、高亮行在两种主题下均 ≥ 4.5 : 1（或 ≥ 3 : 1 若为装饰）。
- [ ] Lighthouse Accessibility ≥ 95。

## 附：对比度计算脚本

```python
def lum(h):
    h = h.lstrip('#'); c = [int(h[i:i+2], 16) / 255 for i in (0, 2, 4)]
    c = [(x / 12.92 if x <= 0.04045 else ((x + 0.055) / 1.055) ** 2.4) for x in c]
    return 0.2126 * c[0] + 0.7152 * c[1] + 0.0722 * c[2]

def ratio(a, b):
    l1, l2 = sorted([lum(a), lum(b)], reverse=True)
    return (l1 + 0.05) / (l2 + 0.05)
```
