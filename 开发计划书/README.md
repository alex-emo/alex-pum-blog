## 工作约定

1. **先读总览**：[00-优化提案总览.md](00-优化提案总览.md) 里有实测基线与任务依赖，单独看某一条容易漏上下文。
2. **一任务一提交**：每个 OPT 编号对应一个 commit，message 写 `opt(01): 阅读量计数移出请求路径`。
3. **回归**：每个任务条目末尾的"验收"一节就是回归清单。`scripts/smoke_test.py` + `curl -I` 是底线。
4. **备份先行**：动数据库（OPT-01、OPT-13）之前先 `venv/bin/python -m scripts.backup`。
5. **实测回填**：改完后把数字填回对应条目的"实测结果 / 优化前 vs 优化后"表格。
6. **不要合并做**：OPT-07（对比度）和 OPT-04（CSP）看起来都只改几行，但前者牵动两套主题 + pygments，后者牵动所有内联脚本，各自独立提交，出问题好回滚。

## 事实勘误

- `deploy/DEPLOY.md:177` 写"验证时应有 HSTS 头"，但当前 Cloudflare Tunnel → uvicorn 链路（无 nginx）并未设置 HSTS，见 [OPT-04](04-安全响应头CSP与HSTS.md)。
- 本地只读挂载下访问文章页返回 500（`attempt to write a readonly database`）是**沙箱现象**，非线上缺陷；它暴露的设计问题归入 [OPT-01](01-阅读量计数异步化.md)。
